# Anthony Hernandez – Portfolio (GitHub Pages)

## Deploy
1. Upload all files (including the `assets/` folder) to the repo root.
2. GitHub → Settings → Pages:
   - Source: `main` / `(root)`
   - Custom domain: `www.anthony-hernandez.net`
   - Enforce HTTPS: ON

## Update
- Replace `assets/avatar.jpg` to update the headshot.
- Replace `assets/Anthony_Hernandez_Updated_Resume.pdf` when the resume changes.
- Edit `index.html` for content/theme.
